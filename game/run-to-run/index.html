About Run to Run

The release date for Run to Run is September 7, 2026, launching exclusively on PC. This online multiplayer party racing game focuses less on pure speed and more on outsmarting opponents by scrambling for markers across dynamic maps and strategically deploying hilarious, unpredictable items. Expect chaotic races where pulling rivals away from the finish line or covering their path in poison is key. If you enjoy quick, chaotic online competition with friends, consider this for your wishlist.
