About 0N35H07

The release date for 0N35H07 is July 18, 2026, on PC. This arcade-style shooter features high-speed projectiles and a minimalist aesthetic where spherical combatants battle across first and third-person perspectives. Set within the digital subconscious of a planet-sized AI, the game emphasizes reflex-driven multiplayer skirmishes backed by an aggressive electronic soundtrack.

What distinguishes this title from standard indie shooters is its open-source foundation, allowing the community to view and modify the underlying code directly. Beyond the technical transparency, the game includes competent bot AI to fill out servers and various character customization options for your combat orb. This is a low-barrier competitive experience designed for players who value mechanical purity and a modifiable engine. Keep an eye on this if you want a free, high-intensity shooter with total community transparency.
