About Shadow Ninja Run

The release date for Shadow Ninja Run is July 21, 2026, on PC. This indie title focuses on fast-paced 2D platforming, tasking you with navigating moonlit rooftops using a specific set of movement tools including double jumps and air dashes. It is a lean, arcade-style experience designed for short bursts of play and tight keyboard control.

While many runners rely on procedural generation, this game uses fifteen handcrafted levels packed with darts, spikes, and blade traps that require precise timing to clear. Success unlocks an endless mode for those who want to push the mechanics further without the constraints of a finish line. The challenge lies in maintaining momentum while managing the cooldowns of your slice and dash abilities to secure a clean run. It is a straightforward pickup for anyone looking for a focused, high-speed platformer.

Buy this if you want a simple, execution-heavy runner with clear goals.
